## 2. الشعار (SVG مرسوم بالكود — لا ملف صورة)

حلقة «ع» مفتوحة يخترقها برق، داخل `viewBox="0 0 64 64"`.

```svg
<circle cx="32" cy="32" r="24" fill="none" stroke="#E63946" stroke-width="11"
        stroke-dasharray="113 38" stroke-linecap="round" transform="rotate(55 32 32)" />
<polygon points="36,10 19,36 29,36 25,56 45,27 34,27" />  <!-- البرق -->
```

- لون البرق: `fill-brand-navy dark:fill-white` — وفي النسخة الفاتحة (`variant="light"`) يصير `fill-white`.
- المقاسات: عادي `h-10 w-10` · مضغوط (`compact`) `h-8 w-8`.
- النص بجانبه: «عاجل» + `<span class="text-brand-red dark:text-brand-red-dark">الآن</span>` بخط `font-headline font-bold`، مقاس `text-2xl` (أو `text-lg` مضغوطاً).
- الـ tagline يظهر تحته فقط في الوضع غير المضغوط: `text-[11px] font-medium tracking-wide`.
- المتغيّر `light` للخلفيات الداكنة: النص `text-white` والفرعي `text-white/60`.

## 5. عناصر بصرية مميّزة

**الفاصل التحريري المزدوج** (`.rule-double`) — خط علوي 3px + خط 1px تحته بفاصل 2px. يُستعمل فوق عناوين الأقسام.

**نظام الأغلفة المرسومة بالكود** — لا صور. كل غلاف = تدرّج + نقش نقطي + حرف زخرفي عملاق:

| المفتاح | التدرّج | الحرف |
|---|---|---|
| `red` | `#8f1d2c → #E63946 → #ff7a5c` | ع |
| `navy` | `#0D1B2A → #16395e → #2e6ea8` | ال |
| `gold` | `#6e5410 → #C9A227 → #ecd26a` | ر |
| `teal` | `#0b3b3f → #12837a → #3ed0b2` | ت |
| `plum` | `#3b1245 → #7c2d8e → #c86bd8` | م |

كلها `linear-gradient(135deg, …)` بمواقع `0% / 55-60% / 100%`.
النقش: `radial-gradient(rgba(255,255,255,0.14) 1px, transparent 1px)` بمقاس `14px 14px`.
يُضاف خطان قطريان بـ SVG بشفافية 20%، والحرف الزخرفي `text-[11rem] text-white/15` أسفل النهاية.

**الحركات:**
- `ticker` — `translateX(0) → -50%` خلال 45s خطياً (شريط الأخبار العاجلة)
- `pulse-dot` — نبض شفافية/حجم خلال 1.6s (نقطة «عاجل»)

## 7. بنية الصفحات والمكوّنات

**المسارات:** `/` · `/search` · `/:category` · `/:category/:slug` · 404

**الهيكل العام:** رأس لاصق (`sticky top-0 z-50`) + محتوى + تذييل كحلي.
الرأس ثلاث طبقات: شريط علوي (التاريخ + الشعار النصي) · صف الشعار والأدوات (بحث + تبديل الثيم) · شريط الأقسام الأفقي بمؤشر سفلي أحمر للقسم النشط.
العرض الأقصى `max-w-7xl` للرأس والتذييل، و`max-w-3xl` لصفحة المقال.

**المكوّنات (`app/components/`):** AppHeader · AppFooter · Logo · Cover · ArticleCard · BreakingTicker · CategoryBlock · HeroSection · MostRead · ShareButtons · Skeleton
